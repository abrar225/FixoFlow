macOS permissions

Checking permissions…

Accessibility lets Fixoflow paste your transcript into the app you were using. Input Monitoring lets the keyboard shortcut work while other apps are focused. Microphone is required to record. macOS applies new grants only to a freshly started app, so after allowing Input Monitoring click Restart Fixoflow. The shortcut then turns on by itself within a second.

Changes apply when you save.
